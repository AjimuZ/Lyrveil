## Failure found and fixed

The first `integration` run failed: the Schemathesis contract test (`backend/tests/integration/test_contract.py`, written in P01.8d and never run before) raised `TypeError: Session.request() got an unexpected keyword argument 'base_url'` in its fixture. In Schemathesis 4.33.0, `from_asgi` forwards unknown keywords to the request that loads the document, so `base_url` is not accepted. The fix passes the `Host` header as `headers` instead. The next `integration` run passed with 48 backend tests, including the contract test. The `lint` level passed after the fix.
