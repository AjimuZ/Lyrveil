## Method

For each document, the status line and the statements about delivered and planned behavior were compared with the
repository: the file lists (`git ls-files`), `compose.yaml`, `frontend/src/app/app.routes.ts`, `backend/pyproject.toml`,
`frontend/package.json`, `config/model-catalog.json`, the routers in `backend/src/lyrveil/main.py`, the committed
`backend/openapi.json`, and the scripts in `scripts/lib/`. The roadmap and the exit files of P01 to P07 gave the state of
each phase.

This was a targeted pass, not a line-by-line audit. The long "Delivered in P0x" notes inside the design documents were
not re-verified one by one; they were written with each task and the exit files of P01 to P07 back them. A statement in
them that no one has checked since may still be wrong.

## Findings that are code or artifact gaps, not documentation

These are now documented as they are. None was changed in code, because this task changes documents only.

1. **`start.cmd` does not start the orchestrator.** `scripts/lib/Lifecycle.psm1` keeps `lyrveil-orchestrator` in
   `DeferredServices`, with the reason "its program comes with P02", though the orchestrator has served the control API
   since P02.6c. On a real installation the backend's scheduler cannot ask for a mode, so no reply is generated by a real
   model. The `e2e` level uses a fake orchestrator, so no test shows it. No roadmap item names the wiring.
2. **`start.cmd` and `status.cmd` print stale reasons.** The warnings still say the catalog and the job queue "come
   with P02". `lyrveil.cli preflight`, which step 6 of `start.cmd` names, does not exist.
3. **`setup.cmd` prints that the model catalog is not available**, though it is; it does not call the `models` command.
4. **`backend/openapi.json` holds only the two health routes.** The other routers are declared with
   `include_in_schema=False`, so the frontend's generated types and the Schemathesis contract test cover only those.
5. **The default text profiles have `quality_evidence: null`**, which the P08 exit forbids. This is expected until the
   quality protocol of P04.10 runs on the hardware.
