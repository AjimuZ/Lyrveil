## What failed and what changed

- **`e2e`, `image-request.spec.mjs`, T-IMG-07:** `getByText('una foto di te seduta al porto')` matched two elements, the user's message and the hint of the closed dialog, which quotes the same example in a longer text. Playwright's strict mode refused it. The spec now passes `{ exact: true }`.
- **`e2e`, `image-request.spec.mjs`, T-CHR-12:** `toHaveText(/^In coda: posizione \d+$/)` never matched the status text, which the template pads with spaces (" In coda: posizione 2 "): a regular expression is matched against the raw text. The expression is now `/^\s*In coda: posizione \d+\s*$/`.
- **`docker`, `ImageRuntime.Tests.ps1`, lock check:** the test joined the continuation lines of `requirements.lock` by replacing the backslash and the line break with a space, which left two spaces after the version and made the pattern `==version( --hash=sha256:...)+` fail on every package. The test now removes the space before the backslash as well. The lock itself was not changed; the test had never run before this exit.
- No product code changed in this task. Both specs and the Pester file had been written in earlier tasks and had not run; this was their first run.
