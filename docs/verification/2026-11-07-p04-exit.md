The `<pre>` in `memory-studio-screen.html` now has `tabindex="0"`, `role="region"` and an accessible name (the existing text "Testo completo del prompt"). This is the one change to shipped markup; it changes no text and no layout. The second `e2e` run passed with no axe finding.
