# Models command, 2026-11-07

Task P01.6c, from Git Bash on Windows 11 with Docker Desktop, on 2026-11-07. Only what was run is listed as run.

## Written

- `backend/src/lyrveil/tools/models.py`, run as `python -m lyrveil.tools.models` by the one-shot `lyrveil-models`
  service of the `tools` profile, now in `compose.yaml` with the network `lyrveil-download`. It imports the standard
  library only, and has the commands `plan`, `download`, `list`, `verify` and `remove`.
- `scripts/lib/Models.psm1` and the `models` command in `scripts/lyrveil.ps1`: options, the Docker, volume and image
  checks, the tier, license acceptance through `Read-Confirmation`, and the refusal of an active profile for `-Remove`.
  `Read-CommandOption` in `scripts/lib/Lifecycle.psm1` gained repeatable options, for `-Model`.
- `backend/tests/unit/test_models_tool.py`: 22 unit tests with scripted HTTP answers and no network.
- `tests/docker/Models.Tests.ps1` (T-DCK-11), `tests/docker/compose.models-test.yaml`, the override of the test
  project `lyrveil-models-test`, and `tests/docker/models-server/`, a local HTTPS server with its own test CA that
  serves generated files and writes the test catalog.
- `docs/models.md` now names `default_tiers`, the field that marks the default profiles of each tier, which the
  catalog format did not name before. The catalog of P02.1a must use it.
