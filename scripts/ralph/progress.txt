# Ralph Progress Log

## Codebase Patterns

- PowerShell scripts: ASCII only, Set-StrictMode -Version Latest, read text with Read-Utf8Text (explicit UTF-8), avoid New/Set/Remove/Start/Stop/Update verbs on private helpers unless SupportsShouldProcess is added, use $script: variables across Pester BeforeAll/It blocks to keep PSScriptAnalyzer clean.
- Never redirect native stderr (2>&1) while $ErrorActionPreference is Stop in Windows PowerShell 5.1; lower it locally first.
- Functions that return an exit code are cast with [int] by the caller, so stray pipeline output fails loudly instead of being read as a pass.
